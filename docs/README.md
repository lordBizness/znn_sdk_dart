# Zenon Dart SDK documentation

Docusaurus site for `znn_sdk_dart`, themed with the
[Zenon design system](https://github.com/digitalSloth/zenon-design-system).

## Local development

```bash
cd docs
npm install
npm run start
```

## Build

```bash
npm run build
```

Outputs a static site to `build/`. `npm run serve` previews the production
build locally.

## Layout

- `docs/` — markdown content (sidebar is autogenerated from folder
  structure and `sidebar_position` frontmatter)
- `src/css/custom.css` — Zenon design tokens mapped onto Docusaurus/Infima
- `static/img/` — brand assets from the design system

## Conventions

Follow the design system when editing:

- Sentence case for headings, labels, and links; no emoji.
- Identifiers, amounts, hashes, and addresses in backticks (rendered mono).
- The plasma gradient appears once, on the intro page CTA — do not reuse it.
- Semantic tokens only in CSS; never raw hex.
