# PlasmaApi

Accessed via `zenon.embedded.plasma`.

Plasma is the anti-spam resource of the Network of Momentum: every account block consumes plasma, obtained either by fusing QSR through the plasma embedded contract or by computing proof of work at send time. This namespace queries an address's plasma and fusion entries, and builds fuse and cancel transactions. `zenon.send(...)` consults this contract internally to decide whether PoW is needed (see [the transactions guide](/guides/transactions)).

## Methods

| Method | RPC | Description |
|---|---|---|
| `get` | `embedded.plasma.get` | Current and maximum plasma of an address |
| `getEntriesByAddress` | `embedded.plasma.getEntriesByAddress` | Paginated fusion entries of an address |
| `getRequiredPoWForAccountBlock` | `embedded.plasma.getRequiredPoWForAccountBlock` | Plasma/PoW requirements for a prospective block |
| `getRequiredFusionAmount` | `embedded.plasma.getRequiredFusionAmount` | Deprecated; not served by the node |
| `getPlasmaByQsr` | (client-side, no RPC) | Convert a QSR amount to plasma |

### Contract methods

Each returns an unsigned `AccountBlockTemplate` addressed to the plasma contract; pass it to `zenon.send(...)`.

| Method | Description |
|---|---|
| `fuse` | Fuse QSR to generate plasma for a beneficiary; minimum `fuseMinQsrAmount` (`10` QSR) |
| `cancel` | Cancel a fusion entry by id, reclaiming the QSR |

## Query methods

### get

```dart
Future<PlasmaInfo> get(Address address)
```

Returns a `PlasmaInfo` with `currentPlasma` and `maxPlasma` (`int`) and the fused `qsrAmount` (`BigInt`) backing it.

### getEntriesByAddress

```dart
Future<FusionEntryList> getEntriesByAddress(Address address,
    {int pageIndex = 0, int pageSize = rpcMaxPageSize})
```

Returns the fusion entries where `address` is the fusing account, as a `FusionEntryList` (total `qsrAmount`, `count`, and a list of `FusionEntry` with `qsrAmount`, `beneficiary`, `expirationHeight`, and `id`). `rpcMaxPageSize` is `1024`.

### getRequiredPoWForAccountBlock

```dart
Future<GetRequiredResponse> getRequiredPoWForAccountBlock(GetRequiredParam powParam)
```

Given a prospective block described by a `GetRequiredParam` (`address`, `blockType`, optional `toAddress`, optional `data`), returns a `GetRequiredResponse` with `availablePlasma`, `basePlasma`, and `requiredDifficulty` — the PoW difficulty needed to cover any plasma shortfall. This is what `zenon.send(...)` uses internally.

:::note Changed in the spec conformance fixes
`GetRequiredParam.fromJson` now tolerates an integer `blockType` as well as a string, and accepts `null` for `toAddress` and `data` (its `toJson` likewise emits `null` for missing `data`). Previously it assumed all fields were present and string-typed. See [the spec conformance fixes](/spec-conformance).
:::

### getRequiredFusionAmount

```dart
@Deprecated('embedded.plasma.getRequiredFusionAmount is not served by the '
    'node; use getPlasmaByQsr for the client-side conversion instead')
Future<int> getRequiredFusionAmount(int requiredPlasma)
```

:::warning Deprecated
This method issues an `embedded.plasma.getRequiredFusionAmount` request, but the node does not serve that RPC endpoint, so the call fails. Use `getPlasmaByQsr` for the client-side QSR-to-plasma conversion instead. Deprecated in [the spec conformance fixes](/spec-conformance).
:::

### getPlasmaByQsr

```dart
BigInt getPlasmaByQsr(BigInt qsrAmount)
```

Client-side conversion (no RPC): returns `qsrAmount * 2100`, the plasma generated by fusing that QSR amount.

## Contract methods

### fuse

```dart
AccountBlockTemplate fuse(Address beneficiary, BigInt amount)
```

Builds a `Fuse` call that sends `amount` QSR (base units, `8` decimals) to the plasma contract, generating plasma for `beneficiary`. The beneficiary can be any address, including the sender's own. The minimum is `fuseMinQsrAmount` (`10` QSR); the QSR is not spent — it stays locked in the fusion entry until cancelled.

### cancel

```dart
AccountBlockTemplate cancel(Hash id)
```

Builds a `CancelFuse` call for the fusion entry with hash `id` (see `FusionEntry.id`). Cancelling is possible once the entry's `expirationHeight` has been reached; the fused QSR is returned to the sender.

## Examples

Fuse `50` QSR for your own address and check the resulting plasma:

```dart
final zenon = Zenon();
final address = await zenon.defaultKeyPair!.getAddress();

final qsr = AmountUtils.extractDecimals('50', coinDecimals);
print('Will generate ${zenon.embedded.plasma.getPlasmaByQsr(qsr)} plasma');

await zenon.send(zenon.embedded.plasma.fuse(address, qsr));

final info = await zenon.embedded.plasma.get(address);
print('Plasma: ${info.currentPlasma}/${info.maxPlasma} '
    '(fused ${AmountUtils.addDecimals(info.qsrAmount, coinDecimals)} QSR)');
```

Cancel an existing fusion entry:

```dart
final zenon = Zenon();
final address = await zenon.defaultKeyPair!.getAddress();

final entries = await zenon.embedded.plasma.getEntriesByAddress(address);
if (entries.list.isNotEmpty) {
  await zenon.send(zenon.embedded.plasma.cancel(entries.list.first.id));
}
```
